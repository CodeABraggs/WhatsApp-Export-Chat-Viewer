## Features

- WhatsApp-style chat bubbles and layout
- Supports Android and iPhone exports
- Open `.zip`, `.txt`, or extracted chat folders
- Photos, videos, voice notes, documents, polls, locations, and stickers
- Search messages and navigate large chats quickly
- Light and dark modes
- Works on desktop and mobile
- Runs entirely in your browser

## How to use

1. Open the [WhatsApp Chat Viewer](https://codeabraggs.github.io/WhatsApp-Export-Chat-Viewer/).
2. Export a chat from WhatsApp.
3. Drop the exported `.zip` or `.txt` file onto the page.
4. View your conversation.

For the best results, export the chat with media included.

## Export a WhatsApp chat

### Android

1. Open the chat and tap **⋮**.
2. Select **More → Export chat**.
3. Choose **Include media**.
4. Save the exported file.

### iPhone

1. Open the chat and tap the contact or group name.
2. Select **Export Chat**.
3. Choose **Attach Media**.
4. Save the exported file to Files.

## Privacy

Your chat files are processed locally in your browser and are **never uploaded** to a server. Do not commit private chats, photos, or other personal files to this repository.

## Run locally

This project is a static HTML, CSS, and JavaScript application. You can either open `index.html` directly or serve the project locally:

```bash
git clone https://github.com/CodeABraggs/WhatsApp-Export-Chat-Viewer.git
cd WhatsApp-Export-Chat-Viewer
npx serve .
```

Then open the local URL shown in the terminal.
